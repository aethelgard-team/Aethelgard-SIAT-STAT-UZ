# Demo yozuvi

Bu papkaga `demo.json` qo'yiladi — `?demo=1` rejimi shu faylni qayta ijro etadi.

Qanday olinadi:
1. Haqiqiy backend ishlab turganda saytda savol bering.
2. Javobdagi raqamni siat.stat.uz dagi raqam bilan solishtiring — mos bo'lsin!
3. "Demo uchun saqlash (demo.json)" tugmasini bosing va faylni shu papkaga qo'ying.

Sinov serveridan olingan yozuvni bu yerga qo'ymang — demo faqat haqiqiy javobni ko'rsatadi.
